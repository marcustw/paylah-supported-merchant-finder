# Project instructions

The repository root owns Git history. The pnpm/Vite application is in `site/`; see `site/AGENTS.md` and `site/README.md`.

The user wants local development and the ability to deploy to Vercel. Prepare deployment configuration when requested; publish or deploy only on an explicit request. Do not recreate ChatGPT Sites hosting.

Keep dependencies, generated builds/releases, test reports, environment files, and local Vercel state out of Git. Commit `site/pnpm-lock.yaml` with dependency changes.

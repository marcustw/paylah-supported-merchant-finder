# Project instructions

This pnpm/Vite app supports local development and Vercel deployment. The Git repository is at the parent directory. Deploy only when explicitly requested; do not recreate ChatGPT Sites hosting. Vercel uses `site/` as its Root Directory and reads `vercel.json` here.

Run `pnpm run dev` for the loopback-only Vite server. Application sources are in `src/`, the HTML entry is `index.html`, and static data/libraries are in `public/`. `dist/` is generated by `pnpm run build`; never edit it.

Verify functional changes with `pnpm test` and `pnpm run test:e2e`. Check `pnpm run build` when changing bundling, assets, or configuration. Keep source code MIT-licensed and preserve third-party notices.
